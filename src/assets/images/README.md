## Organization
- All website images should be placed in this folder
- Use descriptive filenames with hyphens (kebab-case)
- Supported formats: .jpg, .jpeg, .png, .webp
- Recommended size for project images: 500x300px or higher

## Usage
Images are referenced in the projectImages.js configuration file and imported into React components as needed.
